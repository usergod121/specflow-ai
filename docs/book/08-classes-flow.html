3.1 流程：类与调用链

包 flow/ 共 16 个类，真正要认的是下面六个。

类管什么
Node / State五格与三态；顺序由枚举顺序定
Gates / Gate / Facts一格一个判据、一张表、事实的名字
FlowService读状态、写事实、冻结、回退；所有改动串行
Runs一段后台活：立刻返回、只许一段、收场只写一条结论
Journal / Snapshot崩溃恢复那本账 / 改代码前的原文
Actions每格有哪些按钮，只在这里声明

一次动作的调用链

界面 POST /api/flow/freeze {node} │ Api 取参数，不判任何事 │ FlowService.freeze ├ requireReachable 前驱没完成 → 409 + 那句话 ├ Gates.blocked 唯一判据；返回一句话或“能过” ├ 写事实 + 存盘 整份替换 │ └ 返回；界面再问一次 /api/flow 重画
界面 POST /api/node/test/run │ Api 判、拼 prompt、拿产物 │ Runs.start 登记，立刻回“已开始 + 游标” └ 后台线程 ├ Journal.begin 写开工 ├ body.run(progress) 干活，过程写成事件 └ 收场：读这一段的事件，写一条结论 → Journal.end

收场那条结论为什么不在 Runs 里算：轮次、模型调用次数、编译错误——只有干活的知道。 它通过“说一句话”的方式写进事件，Runs 只负责把这一段事件收口成一份载荷，不猜也不补算。

界面拿到的 blockedReason 就是 409 的正文，两处永远是同一句——判据只有一处，话术也就只有一处。
