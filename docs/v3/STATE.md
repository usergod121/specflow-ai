## 待修的 v2 实测缺陷（C1 阶段做掉）

1. **① 的编译在宿主机跑**，容器里没有构建工具 → ⑤ 自己装 Maven 花掉约 28 轮 / 30 分钟（决定性）。
2. **⑤ 轮次上限写死 60**，撞上限立即放弃 → 12 条用例 0 条结论；且摘要恒报 0 条结论（不实）。
3. 缺少**每用例预算 / 超限跳过 / 重试续跑**（用户点名要的）。
4. `$HOME` 被"一律拒"（容器里是正常写法）；`sudo` 在没有 sudo 的容器里还问用户（浪费 187 秒）。
5. `bash` 超时**写死 300 秒**（与配置的 600 不一致）；没有后台任务/日志跟进 → 7 轮纯 sleep（17.5 分钟）。
6. `project.yaml` 的 `build.compile` 在**宿主经 `cmd /c` 执行**，且**不过 `CommandGuard`**。
7. **两套路径世界**：宿主 `E:/…` vs 容器 `/work`；提示词只给了宿主路径。
8. 事件流 append 是 O(总行数)（不缓存换唯一真相，已知取舍）；前端是**轮询**，要改 SSE。
